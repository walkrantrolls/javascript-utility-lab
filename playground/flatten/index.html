Step-by-step execution

The visitor descends into an array while depth remains, and appends each leaf value to a fresh output array.

    What the recursion does

    Each nested array is another branch to visit. The function moves through those branches in order and carries a remaining-depth value. Once it reaches a scalar, or the depth limit, it appends that value to the result.

    01 · VisitRead each item from the current array in order.
    02 · DescendIf the item is an array and depth allows, recursively visit its values.
    03 · CollectAppend scalar values to a new output without changing the input.
    • The default call flattens every nested level, matching flatten(array).
    • Pass a finite depth to stop at a chosen nesting level.
    • Depth zero produces a shallow copy.
