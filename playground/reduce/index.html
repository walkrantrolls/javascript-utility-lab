Document the concept

        

          
01
What is reduce?
It processes present array elements from left to right and returns one accumulated result. The result may be a primitive or a data structure.

          
02
How the accumulator works
Every callback return becomes the accumulator passed to the next visited element. It is the evolving state of the reduction.

          
03
The four callback arguments
Each callback receives accumulator, currentValue, currentIndex, and the original array. With no initial value, the callback begins at the second present element.

          
04
Initial value and sparse arrays
  • Provided initial values seed the accumulator; explicit undefined still counts.
  • Without one, the first present element seeds it; empty and hole-only arrays throw.
  • Sparse holes are skipped while explicit undefined values are visited.

          
05
Internals
The implementation converts the receiver to an object, snapshots its length, finds the starting accumulator when needed, checks index presence, and calls the callback. It never calls native reduce.

          
06
When to choose each method
Use map for one-to-one transformations, filter to select items, and reduce when many items become one summary or a different structure. Prefer map or filter when they express the intent more directly.

          
07
Practical use cases
Totals, grouping, lookup objects, counting, flattening, and building indexes from records.

          
08
Complexity and tests
Time O(n), extra space O(1) excluding the accumulator. Tests cover initial values, sparse arrays, callback arguments, and errors.

Core implementation
Installed as a non-enumerable Array.prototype method; the callback receives all four native arguments.

          
Array.prototype.myReduce = function(callback, initialValue) {
  // Validate the receiver and callback; snapshot length.
  // Use the provided initial value or locate the first present index.
  for (; index < length; index += 1) {
    if (index in object) {
      accumulator = callback(accumulator, object[index], index, object);
    }
  }
  return accumulator;
};
