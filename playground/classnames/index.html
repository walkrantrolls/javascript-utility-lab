What the helper is doing

classNames accepts mixed values, inspects each one, and returns one string. A truthy value enables an object key; a false flag leaves that class out. Your component keeps styling rules beside the state that controls them.

01 · BaseAlways include the button class and selected visual variant.
02 · ConditionsLoading, disabled, and width flags add classes only when enabled.
03 · OutputThe generated string updates both the preview and class list.
  • Arrays can group nested class-name values.
  • Only truthy object keys are included.
  • The helper returns a string; the caller applies it to the UI.
