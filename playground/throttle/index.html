How the window behaves

  1. The first event invokes the callback immediately and starts the timer.
  2. Every event received before the timer expires is ignored; none are queued.
  3. Once the window ends, the next event runs immediately and starts another window.

Unlike debounce, throttle does not wait for activity to stop. It also does not perform a trailing callback in this implementation.
